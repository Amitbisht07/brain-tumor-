# Brain Tumor Detection using Deep Learning

An AI-powered web application that detects brain tumors from MRI scans using a Convolutional Neural Network (CNN). Built with Python, TensorFlow/Keras, and deployed using Streamlit for an easy-to-use interface.

# Features

- Upload MRI brain scan images
- Detect presence of brain tumor
- Predict tumor type (if multi-class model used)
- Clean and simple Streamlit UI
- Fast real-time predictions
- Deep learning based medical image classification

# Tech Stack

- **Python**
- **TensorFlow / Keras**
- **OpenCV**
- **NumPy**
- **Matplotlib**
- **Streamlit**
